# Лапа добра — интернет-магазин товаров для животных с пожертвованиями

Учебный проект по курсу «Fullstack». Лабораторная работа №1: интерфейс приложения и каркас frontend.

## Назначение

Интернет-магазин товаров для животных (корм, аксессуары, лежанки). При оформлении заказа покупатель может добавить пожертвование и выбрать благотворительную организацию (приют или фонд) на интерактивной карте.

## Пользовательские сценарии

1. **Покупка товара.** Открыть каталог, найти товар через поиск или фильтр по категории, добавить его в корзину.
2. **Выбор организации.** Открыть страницу с картой, выбрать приют по отметке на карте или в списке.
3. **Пожертвование.** В корзине выбрать сумму пожертвования, проверить итог и оформить заказ.

## Экраны

| Экран | Адрес | Описание |
|---|---|---|
| Главная | `/` | Приветствие, описание шагов, популярные товары |
| Каталог | `/catalog` | Поиск, фильтр по категориям, сортировка по цене |
| Карточка товара | `/product/:id` | Описание, выбор количества, добавление в корзину |
| Корзина | `/cart` | Список товаров, выбор суммы пожертвования и организации, итог |
| Организации на карте | `/charities` | Карта с отметками, список организаций, выбор получателя |
| Оформление заказа | `/checkout` | Форма с проверкой полей, состав заказа, страница подтверждения |
| Страница не найдена | любой другой адрес | Сообщение об ошибке и ссылка на главную |

## Технологии

- React 18 + TypeScript
- Vite — сборка и dev-сервер
- React Router — клиентская маршрутизация
- Material UI (MUI) — библиотека UI-компонентов
- Leaflet + React Leaflet — карта (подложка OpenStreetMap)

На этом этапе используются демонстрационные данные из каталога `src/data`. Backend и база данных будут добавлены в следующих работах.

## Структура проекта

```
src/
  components/   общие компоненты (шапка, карточка товара, карта, блок пожертвования)
  context/      состояние корзины и выбранной организации
  data/         демонстрационные товары и организации
  pages/        страницы приложения
  App.tsx       описание маршрутов
  main.tsx      точка входа
  theme.ts      тема оформления MUI
  types.ts      типы данных
```

## Запуск frontend

Требуется Node.js версии 18 или новее.

```bash
npm install
npm run dev
```

После запуска приложение доступно по адресу http://localhost:5173.

Сборка для проверки типов и production-версии:

```bash
npm run build
```

Для отображения карты нужен доступ в интернет (загружаются фрагменты карты OpenStreetMap).

## Изменения интерфейса

Здесь фиксируются существенные изменения и упрощения интерфейса.

- Вместо фотографий товаров используются эмодзи на цветном фоне: реальные изображения появятся после подключения backend.
- Оформление заказа не отправляет данные на сервер, заказ подтверждается локально.
